## Operating Protocol

This directory is an air-gapped staging area for public releases. **No file, story, social media post, leaflet, or outreach email may be moved into this directory without documented founder sign-off** recorded in `private/decisions-and-approvals.md`.

### Mandatory Pre-Conditions for Moving Files Here:
1. **Founder Review:** The founder has personally reviewed and approved every sentence of the text.
2. **Attribution Choice Confirmed:** The founder's preference regarding anonymity or attribution (DEC-002) is strictly adhered to.
3. **Medical Sourcing Verified:** All medical references have been verified against current guidelines from Facial Palsy UK, The Brain Charity, or NHS documentation.
4. **Approval Hash Generated:** A deterministic approval hash is recorded in the decisions log.
